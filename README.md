# 行知 · 行测学习工作台

面向江苏常规选调备考的本地学习网站，使用“知识地图 → 典型例题 → 即时复测”的学习流程，并接入完整行测真题题库。

## 打开网站

**公网网址**：[行知学习网站](https://wangwangyyu.github.io/xingzhi-study/)，可分享给他人，无需保持电脑开机。学习记录仍分别保存在各设备浏览器。

**直接打开**：双击 `打开行知.cmd`，或用现代浏览器打开 `index.html`。无需联网、无需安装依赖。

**本地服务**（推荐使用固定地址保存进度）：安装 Node.js 后，在此目录运行：

```sh
npm start
```

然后打开 http://127.0.0.1:4173 。如果端口占用，可以设置 `PORT` 环境变量。

直接文件模式与本地服务模式属于不同的浏览器存储空间，切换前请使用“学习设置与备份”导出，再在新入口导入。手机访问：双击 `手机访问.cmd`，手机与电脑连接同一 Wi-Fi，在手机浏览器输入启动窗口显示的手机访问地址（端口 4174）。使用期间保持电脑开机且不休眠。如 Windows 防火墙提示 Node.js 网络访问，请允许当前家庭/专用网络。电脑 IP 改变后，以启动窗口显示的新地址为准。默认 `npm start` 仍只监听本机；手机入口仅提供网站与题库资源。

## 已有功能

- 知识地图按来源思维导图收录 32 个专题、175 条知识要点，支持关键词搜索和模块筛选；对公式或逻辑问题标注校正。
- 36 张原创知识卡，含方法步骤、识别信号、易错边界、例题及独立复测，共 72 道原创训练题。
- 收录 ERRRC/xingcezhenti 的 58,890 道题、515 套试卷，覆盖政治理论、常识、言语、数量、判断推理、资料分析六个模块；保留原卷重复出现的题目。
- 真题按 50 题分页展示，支持模块、年份、地区、题型筛选及题干、试卷、qid 搜索；点击后才读取对应试卷文件，图片与公式保存在本地。
- 支持多选题与 8 个选项；缺少选项、答案或题目必要配图的条目标为“仅阅读”，不会判分。解析缺图会显示提醒。
- 原有 2025 年江苏 A 类判断推理回忆题保持兼容，附 qid、来源文件和第三方参考解析。
- 选择答案后才显示解析；独立复测正确才计为通过。
- 模块筛选、考点和题干关键词搜索、5题练习、模块专项练习。
- 错题自动入队，重新作答正确后移出；历史记录保留。
- 基于真实作答的七日统计、正确率、连续练习和模块进度。
- 每日练习目标自定义（1–999 题）、侧栏备考方向自定义、JSON 备份导出与校验导入。
- 键盘操作、移动端布局、减少动画偏好适配。

## 内容范围与来源

思维导图由本项目解析为可搜索的专题和要点。知识卡与原创训练题由本项目编写；地图提供较完整的行测框架，知识卡仍是循序学习路线，并非每条要点都有独立讲解课程。预计学习时间是建议值，不是实测计时。导入的完整题库是第三方整理资料，不代表官方题库或江苏常规选调专项题库。

完整真题来源：[ERRRC/xingcezhenti](https://github.com/ERRRC/xingcezhenti)，固定提交见 `question-bank/SOURCE.md`。题目、共享材料和 39,461 张图片保存在 `question-bank/`；索引保留 58,890 次原卷题目出现、27,473 个唯一 qid。`sourceNumber` 是来源文件内序号，不保证对应原卷题号。缺少题干、选项或共享材料所需图片的题目标记为仅阅读；详细导入问题见 `question-bank/import-report.json`。原 28 道 2025 江苏 A 类判断推理回忆题仍保留在 `real-questions.js` 以兼容原创例题流程。

来源将解析称为“官方解析”，但本项目未核实考试主管部门出处，统一显示为“第三方参考解析”。未对每道参考解析作权威认证，争议题应结合其他可靠来源核对。政治理论、法律、时政与报考信息应结合现行文件及目标年份官方考纲核对。

## 学习数据

所有学习记录只保存在当前浏览器的 localStorage，键名 `xingzhi-study-v1`；没有账号、云端同步、广告、统计追踪或远程模型调用。清除浏览器数据会删除本地进度。用“学习设置与备份”进行备份。浏览学习不计为通过；答对独立复测才更新考点进度。固定题重复答对不等于已经掌握所有变式。

## 文件与维护

- `data.js`：原创知识卡、例题和复测题。
- `行测知识点思维导图.md`：知识地图内容来源。
- `scripts/build-map.cjs`、`knowledge-map.js`：将 Markdown 专题与要点构建成结构化地图数据，并校验课程映射。
- `real-questions.js`：原有江苏回忆题兼容数据。
- `question-bank/catalog.js`、`bank.js`、`question-bank/papers/`：完整题库索引、按需加载器和分卷题目内容。
- `question-bank/images/`：题库配图与公式图。
- `domain.js`：记录校验、进度、错题、日期与统计逻辑。
- `app.js` / `styles.css`：页面、交互和样式。
- `scripts/import-bank.py`：从固定版本的来源仓库重新导入完整题库。
- `server.js`：默认监听本机的静态服务器；`手机访问.cmd` 启用局域网访问。

运行内容及学习记录测试：

```sh
npm test
```

浏览器测试 `node tests/browser.cjs` 需要 Playwright 与 Chrome；可通过 `PLAYWRIGHT_MODULE_DIR`、`CHROME_PATH` 指定本机路径。该测试使用独立浏览器上下文，不影响用户真实记录。

前端设计参考了 [Anthropic frontend-design skill](https://github.com/anthropics/skills/tree/main/skills/frontend-design)，未使用第三方前端运行依赖。
